# GitHub Rescue Mission

Welcome to the 10-minute GitHub Rescue Mission.

Your goal is to fix a small production-status error using a professional GitHub workflow.

IMPORTANT:
- Do not edit `main` directly.
- Create a branch called `fix-release`.
- Change `System Status: Offline` to `System Status: Online`.
- Commit the change.
- Open a Pull Request.
- Review the diff.
- Merge only if the change is correct.

Follow the student activity sheet provided by your instructor.
